# FindIt – Campus Lost and Found

FindIt is a local-first Android app built with Flutter, Dart, and SQLite. Accounts, item reports, matches, conversations, messages, and in-app notifications are stored on the device. Report and profile photos are copied to the app's documents directory.

## Requirements

- Flutter SDK and Dart (use the versions required by the installed Flutter SDK)
- Android Studio with Android SDK and an Android emulator or device

## Run on Android

1. Open this folder in VS Code or Android Studio.
2. Connect an Android device or start an emulator.
3. In the project terminal, run:

   ```sh
   flutter pub get
   flutter run
   ```

To produce an installable release APK, run `flutter build apk --release`. The APK is written to `build/app/outputs/flutter-apk/app-release.apk`.

## Run in Chrome

From the project terminal, run:

```sh
flutter pub get
flutter run -d chrome
```

For a deployable web build, run `flutter build web` and serve the `build/web` directory over HTTP. The SQLite web support files in `web/` are generated by `dart run sqflite_common_ffi_web:setup`; keep them with the project when building or deploying.

The database is named `findit.db` and is created/migrated by `lib/database.dart`. Android uses the device's SQLite database and documents directory; Chrome runs SQLite in WebAssembly and stores it in the browser's IndexedDB, with photos saved in that database. Browser accounts and data are separate from Android accounts and data, and are scoped to the browser profile and site origin. User passwords use salted PBKDF2-HMAC-SHA256 hashes; the session user ID is kept in local shared preferences. No remote service is used for app data.
